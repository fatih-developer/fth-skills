# Font Sources

Licenses change and vary per family. Treat this page as a map of where to look, and verify the license of every font you propose at the source.

## Libraries with open or free licenses

| Source | What it offers | Notes |
|---|---|---|
| Google Fonts (fonts.google.com) | Large open-source library (mostly SIL OFL), hosted CSS API, metadata used by `find_fonts.py` | Popularity makes the top families look generic; use `find_fonts.py` to go past them |
| Fontshare (fontshare.com) | Free families from Indian Type Foundry | Several of its families (Satoshi, General Sans, Clash Display, Switzer, Cabinet Grotesk) are frequent AI/template picks; check the site's license terms and Turkish coverage |
| Velvetyne (velvetyne.fr) | Libre, often experimental display faces | Good for distinctive headlines; many are display-only |
| Collletttivo (collletttivo.it) | Open-source typefaces by independent designers | Check each family's license and glyph set |
| The League of Moveable Type (theleagueofmoveabletype.com) | Classic open-source families | Mostly display and headline use |
| Open Foundry (open-foundry.com) | Curated open-source families with specimens | Useful for finding less common OFL faces |
| Uncut (uncut.wtf) | Catalog of free and open typefaces | Licenses differ per entry |
| Font Squirrel (fontsquirrel.com) | Fonts described as free for commercial use | Read each license; not all include web embedding |

## Commercial options

Adobe Fonts (subscription) and independent foundries (for example Klim, Grilli Type, Commercial Type, Dinamo, Pangram Pangram) offer distinctive families. Suggest them only when the user has a budget, state that web licensing is paid and priced by traffic or domains, and always offer an open-license alternative in the same direction.

## References for typography in use (inspiration, not sources)

- Fonts In Use (fontsinuse.com): real-world usage by industry and format.
- Typewolf (typewolf.com): type in use on websites and pairing examples.
- The domain's own printed material: signage, forms, packaging, documents.

## Checks for any font outside Google Fonts

1. License allows web embedding (self-hosting) and the intended use.
2. Glyphs: ğ Ğ ş Ş ı İ ç Ç ö Ö ü Ü and `₺` are present and well drawn.
3. Files: WOFF2 available, weights needed exist, file size acceptable.
4. Record the source URL and license in `design-research.md` and `DESIGN.md`.

# Checklists

## Prompt Draft Checklist

- request type detected correctly
- goal is explicit
- constraints are visible
- output contract is concrete
- tool usage rules exist when relevant
- missing context was kept to the minimum needed

## Agent Checklist

- role is narrow enough
- tools are scoped clearly
- escalation rules are explicit
- risky actions require approval
- fallback behavior is defined

## Workflow Checklist

- stages are ordered logically
- quality gates exist
- uncertainty handling exists
- human checkpoints exist where needed

## MCP Package Checklist

- system behavior is bounded
- tool descriptions are specific
- permissions are least-privilege
- approval rules cover destructive actions
- config scaffold does not overclaim runtime correctness

## Evaluation Checklist

- clarity reviewed
- completeness reviewed
- model or tool alignment reviewed
- robustness reviewed
- top failure modes identified
